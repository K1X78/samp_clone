## Duplicate claims and edge notes

The only prior same-start claims found in `src/` are three separate scoreboard-core adapters: GetCount 0x100138c0 (`src/client/render/scoreboard_list.cpp:10`), GetScore 0x1006e290 (`:18`), GetPing 0x1006e2b0 (`:22`). These run in `samp_client_core`, not as additional normal DLL player-pool methods. All other exact starts in this file have no existing source mapping. The `playerinfo` CPlayerInfo constructors/destructor are the verified callees already documented in `client-luna-playerinfo.md`; no extra body evidence is inferred from their comments.

Many methods intentionally preserve ID1004 access even though arrays are declared with 1004 entries. Create/GetName/GetScore/GetPing/GetPlayerInfoFlag/GetPlayer/GetPlayerInfo/SetName/SetAt can touch adjacent layout at 1004; Delete/IsConnected instead reject 1004. Header comments retain this, but adjacency is not proven. `Process` has a normal-flow match only; it remains UNRESOLVED because official C omits the remote exception cleanup while source has `GameExceptionFilter`/Remove handling, and its discontiguous body ranges omit the exception region. No mismatch patch is recommended until that path is resolved.
