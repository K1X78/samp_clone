# P1.1: transport fragmentation and reliability

Status, 2026-11-03: **implementation and deterministic offline gate complete**.
P1.1 is one of seven packages in Division P1. All seven are covered in the
[P1 completion report](../P1_REPORT.md). Live interoperability remains a
separate, explicitly requested validation gate.

## Delivered behavior

The real client and server use the shared `ReliabilityFrame` codec and state.
Frames retain exact bit lengths, message numbers, split metadata and channel
indexes across retries. Large raw messages fragment to a 1492-byte IP MTU with
28 bytes reserved for IP/UDP. The receiver reassembles complete groups in index
order and preserves a partial final byte. Main-loop query limits now apply only
to query requests, allowing full game fragments into the transport.

Reliable receipt creates ACKs, duplicates are re-ACKed, and incoming ranges
remove pending frames. ACK-only padding is accepted. Sparse output is divided
into at most 256 ranges per datagram. Ordered and sequenced channels maintain
separate counters. Ushort comparison, the timestamped missing-receipt deque,
expiry boundaries and wraparound follow the recovered original operations.

Retry delay uses `max(30, ping * 3)` milliseconds. Ping clamping, timeout since
last ACK, five-sample RTT filtering, native initial ping/retry values, four send
priorities and resend-first scheduling replace the earlier fixed-delay host.
The congestion controller uses native epoch thresholds and stored-float
arithmetic boundaries; isolated original-DLL fixtures compare those operations.
The bandwidth credit is bounded to one second at 512000 bits/second.

The client sends raw frames from gameplay/control producers before encoding;
remaining small legacy UI frames are adopted into shared retry state during the
tick. Server sends carry bit count and priority. Connection cleanup releases
split/ordered/queued/retry state. Client packet dispatch reaches the ACK/retry
pass, and complete layouts distinguish unconnected controls from connected data.

Explicit host bounds remain 4 MiB buffered payload, 32 split groups, 4096
fragments per group, 1024 ordered messages and 4096 queued/pending frames.
Reliable capacity failure closes the connection; unreliable incomplete groups
expire after ten seconds. These are host resource policies, not asserted
original allocator limits.

local 0.3.DL PE. Print instructions on demand with
`python tools/read_reference_function.py client ADDRESS --asm`. The windows
below may cover an operation rather than an entire function. The full binary
SHA-256 is recorded. Evidence came from local PE readers, not an unavailable
REA provider.

`0x10047b30`. These ownership corrections establish provenance, not full parity.

## Verification

`transport_test` passes literal wire fixtures, malformed/truncated fields,
ACK-only and sparse ACK batches, independent channel modes, loss/reorder/retry,
duplicate delivery suppression, 70000 message numbers crossing rollover,
receipt-hole expiry, a 9001-byte partial-tail split payload, capacities,
priorities, timeouts and actual server/socket-free client queue paths.
`official_transport_test` compares isolated original sequence, retry, header,
ping and congestion arithmetic, including x87 float boundaries.

The full Win32 suite passes 9/9 CTest targets and 7/7 Python counter regression
tests. [Validation identity](P1_1-validation.json) links the full build record,
source fingerprint and artifact hashes. P0 evidence remains unchanged.

No game or live server was launched. The original-DLL helper oracle suppresses
DllMain via `DONT_RESOLVE_DLL_REFERENCES`. Actual endpoint interoperability,
in-engine timing and larger network scenarios await the explicit runtime gate.
